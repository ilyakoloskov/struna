# STRUNA

Тренажёр для гитариста (PWA): подключаешь гитару через звуковую карту, ноты едут по дорожке,
приложение в реальном времени распознаёт сыгранное и начисляет очки. Плюс инструменты музыканта:
тюнер, квинтовый круг, ноты на грифе, гаммы и лады.

Сайт: https://ilyakoloskov.github.io/struna/

## Возможности
- Игра по MIDI и Guitar Pro (с табулатурой), 6 и 7 струн, строи-пресеты и свой строй
- Распознавание высоты (YIN в AudioWorklet), начала ноты, проверка аккордов по хромаграмме
- Приёмы из Guitar Pro: флажолеты, бенды, слайды, хаммеры, палм-мьют, глухие ноты
- Темп 50–100 %, петля на фрагмент, калибровка задержки, история прогресса
- Тюнер, квинтовый круг, гриф с гаммами, позициями и CAGED, упражнения «сыграй гамму»
- Работает офлайн, треки и рекорды хранятся в браузере (IndexedDB)

## Разработка
Node 22.22.3 (`.nvmrc`). Зависимости ставить через npm 11 (у npm 10 баг на peer-зависимостях jsdom):

```sh
npx npm@11 install
npm run dev        # локальный сервер
npm test           # тесты (Vitest)
npm run build      # проверка типов и сборка
```

Пуш в `main` публикует сайт на GitHub Pages (`.github/workflows/deploy.yml`).
