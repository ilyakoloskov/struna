# STRUNA — стартовый пакет

Всё для старта проекта в VS Code с Claude Code.

## Что внутри
- `CLAUDE.md` — промпт и план проекта. Положите в корень репозитория: Claude Code читает его в каждой сессии.
- `design/` — визуальный концепт:
  - `01-game-7-strings.png` — игровой экран, 7 струн
  - `02-game-6-strings.png` — игровой экран, 6 струн
  - `03-tuner.png` — тюнер
  - `04-results.png` — результаты
  - `05-circle-of-fifths.png` — квинтовый круг
  - `06-fretboard.png` — гриф и лады, живая подсветка
  - `tokens.md` — цвета, шрифты, эффекты
  - `html/` — статичная HTML-разметка экранов (открываются в браузере) и шрифты с лицензиями OFL

## Как начать
1. Создайте пустую папку проекта, скопируйте туда `CLAUDE.md` и папку `design/`, сделайте `git init`.
2. Откройте папку в VS Code с Claude Code.
3. Напишите: «Прочитай CLAUDE.md и папку design. Начинаем этап 1».
4. Идите строго по этапам из `CLAUDE.md`. Этап закрыт, когда выполнены его критерии «Готово, когда».
5. После каждого этапа: коммит + пара строк в раздел «Что уже сделано» в `CLAUDE.md`.

Цифры и названия на макетах — примерные, для вида.
