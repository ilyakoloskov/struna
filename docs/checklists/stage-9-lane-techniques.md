# Дорожка: читаемые лады и приёмы — ручная проверка

Нужно: гитара через звуковую карту, Chrome/Edge, `npm run dev`, GP-файл с приёмами
(флажолеты, бенды, слайды, хаммеры, палм-мьют, глухие ноты). GP-треки, добавленные раньше, —
удалить из библиотеки и добавить заново: приёмы читаются только при импорте.

## 1. Читаемость ладов

- [ ] `/play/test?fps` — ноты стоят «лицом» к игроку, номера ладов белые с тёмной обводкой, читаются издалека
- [ ] Двузначные лады (10–24) помещаются на плашке
- [ ] Ближняя нота перекрывает дальнюю на той же струне (а не наоборот)
- [ ] Bloom: плашки светятся, цифры чёткие, не размыты свечением
- [ ] Промах — плашка серая, цифра приглушена; заход перед петлёй — тусклый
- [ ] 6 и 7 струн, окно 16:9 и узкое — всё на месте, 60 fps

## 2. Знаки приёмов (тестовые ноты, 3-й такт)

- [ ] Флажолет — ромб, номер лада внутри
- [ ] Бенд — «↑1» над нотой; бенд с отпусканием — «↑½ ↓»
- [ ] Хаммер-он — «h», слайд — «↗», палм-мьют — «PM» и тёмная полоса снизу, глухая — тёмная плашка с «×», вибрато — «~»

## 3. GP-файл с приёмами

- [ ] Натуральный флажолет на 12/7/5-м ладу — ромб на том ладу, что в табулатуре
- [ ] Бенды, пребенды, отпускания — знаки совпадают с табулатурой
- [ ] Хаммер/пулл — «h»/«p» на второй ноте; легато-слайд — «↗»/«↘» на первой
- [ ] Строй в настройках не совпадает с файлом — флажолеты и слайды пропадают, бенды/PM/вибрато остаются

## 4. Судейство с гитарой

- [ ] Бенд: удар и подтяжка — засчитывается (и если подтянул не до конца)
- [ ] Пребенд: подтянул, ударил, отпустил — засчитывается
- [ ] Слайд в ноту снизу — засчитывается, хотя начало звучит ниже
- [ ] Хаммер-он и пулл-офф без удара медиатором — вторая нота засчитывается
- [ ] Легато-слайд к ноте — целевая нота засчитывается без удара
- [ ] Глухая нота (×) — засчитывается удар по заглушённой струне
- [ ] Палм-мьют — засчитывается по высоте, как обычная нота
- [ ] Натуральный флажолет на 12-м, 7-м, 5-м ладу — засчитывается (звучащая высота)
- [ ] Искусственный (pinch) флажолет — отметить, засчитывается ли (детектор может слышать основной тон)
- [ ] Щелчки и шум между нотами не дают «лишних нот» в результатах

## Если что-то не так — записать

Файл, такт, приём; что видно на дорожке и что в табулатуре; засчиталось ли и с какой оценкой.
