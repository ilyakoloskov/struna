# Этап 8 — ручная проверка удобств

Критерий этапа: можно замедлить и зациклить сложный кусок и видеть прогресс.
Нужны гитара и звуковая карта (калибровка и практика имеют смысл только с живой игрой).

## Подготовка

- [ ] `nvm use && npm run dev`, Chrome или Edge; гитара настроена

## 1. Калибровка — `/settings` (или «Калибровка задержки» в тюнере)

- [ ] Блок «Вход звука»: устройство, уровень; «Строй», A4; «Вид» — скорость нот
- [ ] «Начать калибровку»: 4 щелчка вступления, затем 16 — бить по заглушённой струне на каждый
- [ ] «Услышано ударов» растёт с каждым ударом
- [ ] Итог: «Поправка N мс · разброс ±M мс · K ударов» → «Сохранить поправку»
  - у звуковой карты поправка обычно в пределах ±40 мс, разброс — ±5…15 мс
  - если бил специально рано — поправка отрицательная, поздно — положительная
- [ ] Повторная калибровка даёт близкое значение (±10 мс)
- [ ] Мало ударов / неровно — понятное сообщение, «Ещё раз»
- [ ] Ручной ползунок поправки работает и сохраняется после перезагрузки
- [ ] В игре «Задержка N мс» внизу справа учитывает поправку
- [ ] **Главное:** после калибровки при честной игре по нотам — в основном Perfect (до калибровки было больше Good?)

## 2. Темп

- [ ] В паузе — темп 50 / 60 / 70 / 75 / 80 / 90 / 100 %
- [ ] На 50 % трек играет вдвое медленнее, высота нот не меняется, ноты на дорожке едут медленнее
- [ ] Ноты приходят на линию удара в такт со звуком и на медленном темпе
- [ ] Отсчёт и метроном тоже медленнее
- [ ] Попадания на медленном темпе засчитываются так же точно
- [ ] Внизу справа «Темп 75 %», в подзаголовке «практика»

## 3. Петля

- [ ] В паузе «Зациклить это место · 4 такта» → на полосе прогресса жёлтая пунктирная рамка, внизу «Петля 1:52–2:05»
- [ ] Каждый повтор начинается за такт до петли: музыка играет, ноты захода тусклые и не судятся
- [ ] Ноты после конца петли на дорожке не показываются
- [ ] Справа «Повтор N · прошлый X % · лучший Y %» обновляется после каждого прохода
- [ ] Переход на новый повтор не «заикается»: ритм и звук непрерывны
- [ ] Петля + замедление вместе
- [ ] «Закончить практику» → результаты с пометкой «петля … · практика — в рекорд не идёт»
- [ ] «Убрать петлю» → обычная игра

## 4. Результаты и прогресс

- [ ] «Медленнее · 75 %» → трек на 75 %; ещё раз — 50 %
- [ ] «Сложный участок … Зациклить» → петля на этот участок на замедленном темпе
- [ ] Практика (замедление/петля) не ставит «Новый рекорд», рекорд на карточке трека не меняется
- [ ] «Прогресс · N попыток»: линия точности по попыткам; полный темп — сплошные точки, практика — полые; наведение — подсказка с датой и темпом
- [ ] «+N п. п. с первой попытки» — когда есть 2+ попытки на полном темпе
- [ ] «Чаще всего ошибаешься» — участки по всем попыткам, «Зациклить» у каждого
- [ ] После перезагрузки всё на месте (IndexedDB)

## 5. Упражнение «сыграй гамму» — `/theory/fretboard`

- [ ] Под грифом блок «Упражнение»: выбрать темп, «Играть гамму»
- [ ] Гамма вверх и вниз восьмыми под метроном, ноты — только в выбранном диапазоне ладов
- [ ] Узкий диапазон (например, 5–8) — играется в одной позиции без переездов
- [ ] Широкий диапазон — подсказка сузить
- [ ] Результат упражнения сохраняется, у каждой гаммы/позиции/строя — своя история прогресса
- [ ] «Медленнее» и «Ещё раз» на результатах упражнения ведут обратно в упражнение
