# Этап 9 (часть 1) — ручная проверка Guitar Pro и табулатуры

Критерий: GP-файл загружается в библиотеку, в игре струны, лады и строй берутся из файла,
табулатура видна в библиотеке с курсором, синхронным с воспроизведением.
Нужны 2–3 своих файла Guitar Pro разных версий (.gp5, .gpx, .gp) — с сайтов табов; желательно один в Drop D/Drop C
или 7-струнный, один с повторами (|: :|), один с несколькими гитарами.

## Подготовка

- [ ] `nvm use && npm run dev`, `/library`

## 1. Импорт

- [ ] «Выбрать файл» / перетаскивание .gp, .gp3, .gp4, .gp5, .gpx, .gp7 — трек добавился, видно «Исполнитель — Название»
- [ ] Первая загрузка GP чуть дольше (подгружается модуль Guitar Pro), дальше — быстро
- [ ] Гитарная дорожка выбрана правильно; в списке — все дорожки файла
- [ ] Повреждённый файл / переименованный не-GP — понятное сообщение
- [ ] Перезагрузка страницы — трек на месте

## 2. Строй

- [ ] Файл в другом строе (например, Drop D, а выбран 7-струнный стандарт) — фиолетовая плашка «В файле строй … — позиции пересчитаны»
- [ ] «Играть в строе файла» — строй переключился (пресет или «Свой строй»), плашка исчезла; строй поменялся и в тюнере
- [ ] Строй совпадает — позиции в «Нотах» те же, что в табулатуре файла (струна и лад)

## 3. Табулатура

- [ ] Переключатель «Табулатура / Ноты»; табулатура в тёмной теме, читается
- [ ] Видны строй, темп, повторы, аккорды, залиги, номера тактов
- [ ] «Играть» — курсор идёт в такт со звуком; на повторе возвращается к началу повторяемого фрагмента
- [ ] Табулатура прокручивается вслед за курсором
- [ ] Клик по такту/ноте — воспроизведение перематывается туда
- [ ] Смена гитарной дорожки — табулатура перерисовывается для неё
- [ ] Длинный файл (5+ минут) — рисуется за разумное время, страница не подвисает

## 4. Игра

- [ ] «Играть» — ноты на дорожке на тех же струнах и ладах, что в файле
- [ ] Аккомпанемент (бас, барабаны, другие гитары) звучит своими сэмплами
- [ ] Повторы и смены темпа — ноты приходят в такт со звуком весь трек
- [ ] Трек проходится до конца, результат сохраняется

## 5. Без сети

- [ ] После одной загрузки GP онлайн — открыть табулатуру и импортировать новый GP без сети (модуль и шрифт в кэше)

## Если что-то не так — записать

Файл (версия GP), дорожка, такт; что ожидалось (по Guitar Pro / TuxGuitar) и что видно.

- [ ] Есть проблемы → принести заметки, правим до коммита
