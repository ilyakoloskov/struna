# Этап 4 — ручная проверка загрузки MIDI

Критерий этапа: загруженный MIDI проигрывается, ноты гитарной партии видны списком со струной и ладом.
Гитара для проверки не нужна — только наушники/колонки и пара своих MIDI-файлов
(лучше с гитарной партией, басом и ударными; с сайтов табов обычно есть экспорт в MIDI).

## Подготовка

- [ ] `nvm use && npm run dev`, открыть http://localhost:5173/library в Chrome или Edge
- [ ] Звук включён

## Демо-трек

- [ ] «Демо-трек» → появилась карточка, справа детали трека
- [ ] Индикатор «Загружаю сэмплы…» доходит до конца (первый раз — несколько секунд, интернет нужен)
- [ ] «Играть»: 4 щелчка отсчёта, затем бас и барабаны; гитары не слышно (её играешь ты)
- [ ] «Слышать гитарную партию» — гитара появляется; выключить на ходу — обрывается сразу
- [ ] «Метроном» — щелчки по долям, сильная доля выше
- [ ] «Отсчёт такта» выкл → старт сразу без щелчков
- [ ] Пауза / продолжение с того же места; ■ — в начало
- [ ] Перемотка ползунком во время игры — звук продолжается с новой позиции без «хвостов»
- [ ] Строка звучащей ноты подсвечена; «Следить за воспроизведением» прокручивает список
- [ ] Рифф лежит в открытой позиции: E2 — 6-я открытая, G2 — 6-я 3-й лад, A2 — 5-я открытая
- [ ] Звук не плывёт и не заикается, если в это время скроллить страницу и переключать вкладки браузера

## Свой MIDI-файл

- [ ] «Выбрать MIDI» или перетаскивание файла — трек добавился и выбран
- [ ] Название трека и дорожек читается (в т.ч. по-русски, без «кракозябр»)
- [ ] Гитарная дорожка выбрана автоматически правильно; если нет — выбрать вручную в списке
- [ ] Остальные дорожки звучат своими инструментами (бас — басом, клавиши — клавишами, ударные — барабанами)
- [ ] Темп и размер в заголовке совпадают с ожидаемыми; трек со сменой темпа играет без сбоев
- [ ] Время нот в списке совпадает со звучанием (подсветка строки идёт в такт)
- [ ] Повторная загрузка того же трека — сэмплы уже из кэша, почти мгновенно

## Струны и лады

- [ ] Позиции «гитарные»: гамма и риффы в одной позиции, без лишних прыжков по грифу
- [ ] Аккорды — на разных струнах, растяжка не больше 4 ладов
- [ ] Сменить строй 7 → 6 струн: ноты ниже E2 помечены «нельзя сыграть», сверху предупреждение с их числом
- [ ] Drop D / Drop A: низкие ноты переезжают на 6-ю/7-ю струну
- [ ] Сравнить 10–20 нот с настоящей табулатурой этого трека: где расстановка неудобная — записать

## Ошибки

- [ ] Переименовать любой файл в `.mid` и загрузить — понятное сообщение «Файл не похож на MIDI»
- [ ] Без интернета (DevTools → Network → Offline) новый трек: предупреждение «Не загрузились сэмплы…», приложение не падает
- [ ] В консоли нет ошибок

## Если что-то не так — записать

Файл (можно приложить), дорожка, строй; что ожидалось и что видно.
Для расстановки — время ноты, какая позиция получилась и какая удобнее.
