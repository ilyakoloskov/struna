# Этап 7 — ручная проверка PWA и хранения

Критерий этапа: приложение ставится, работает без сети, треки и рекорды сохраняются.
Service worker работает только в production-сборке: проверять через `npm run build && npm run preview`.

## Подготовка

- [ ] `nvm use && npm run build && npm run preview`, открыть адрес из консоли (localhost) в Chrome или Edge
- [ ] DevTools → Application → Manifest: имя, иконки, `fullscreen`, `landscape` — без ошибок
- [ ] DevTools → Application → Service workers: `sw.js` activated and running

## 1. Установка

- [ ] В шапке появилась кнопка «Установить» (или иконка установки в адресной строке)
- [ ] Установить → приложение открылось в отдельном окне на весь экран, иконка — дорожка со струнами
- [ ] Кнопка «Установить» в установленном приложении не показывается
- [ ] На рабочем столе / в Launchpad / в меню «Пуск» — иконка STRUNA

## 2. Хранение

- [ ] `/library`: загрузить 2–3 своих MIDI и демо-трек
- [ ] Выбрать у трека другую гитарную дорожку
- [ ] Перезагрузить страницу → треки на месте, выбранная дорожка сохранилась
- [ ] Сыграть трек (можно `?autoplay` в адресе игры) → результат открылся
- [ ] Перезагрузить страницу результатов → результат на месте
- [ ] В карточке трека — «рекорд N»; сыграть ещё раз лучше → «Новый рекорд» и обновлённый рекорд
- [ ] Удалить трек (×) → после перезагрузки его нет, его результаты тоже исчезли
- [ ] Закрыть браузер полностью, открыть снова → всё на месте

## 3. Без сети

- [ ] Пока есть сеть — один раз открыть каждый трек на игру (скачаются сэмплы инструментов)
- [ ] Выключить Wi-Fi (или DevTools → Network → Offline)
- [ ] Перезагрузить → приложение открывается; работают главная, библиотека, тюнер, теория, настройки
- [ ] Шрифты Unbounded/Manrope на месте (заголовки — широкие)
- [ ] Трек, открытый раньше, играет без сети (сэмплы из кэша)
- [ ] Новый трек без сети: открывается, а для неизвестных инструментов — понятное предупреждение
- [ ] Тюнер с гитарой работает без сети
- [ ] Результаты сохраняются и без сети

## 4. Обновление

- [ ] Поменять любой текст в коде, `npm run build`, перезапустить `preview`, обновить страницу
- [ ] Появилось «Доступна новая версия STRUNA» → «Обновить» → новая версия
- [ ] Во время игры уведомление не появляется (оно только вне экрана игры)

## 5. Экран и мобильные

- [ ] Во время игры экран не гаснет (поставить короткий тайм-аут сна в системе и играть дольше него); на паузе — гаснет как обычно
- [ ] С телефона/планшета (тот же Wi-Fi, адрес через `npm run preview -- --host` и HTTPS-туннель — getUserMedia требует HTTPS):
  - [ ] в тюнере и перед игрой — предупреждение о большей задержке микрофона
  - [ ] приложение открывается и ставится на домашний экран

## Если что-то не так — записать

Браузер и ОС, шаг, что видно; для офлайна — что именно не открылось (DevTools → Console и Application).
