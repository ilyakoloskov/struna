# Этап 6 — ручная проверка игры

Критерий этапа: можно сыграть трек от начала до конца и получить результат.
Нужны гитара, звуковая карта и наушники/колонки. Тюнер (этап 2) лучше проверить раньше — игра использует тот же детектор.

## Подготовка

- [ ] `nvm use && npm run dev`, Chrome или Edge
- [ ] Гитара настроена (`/tuner`), в настройках выбран правильный строй
- [ ] Сначала без гитары: `/play/demo?autoplay` — бот играет сам, доходит до экрана результатов

## 1. Демо-трек с гитарой — `/play/demo`

- [ ] Стартовый экран: «Гитара подключена» (или кнопка «Подключить гитару» → разрешить доступ)
- [ ] «Начать» → отсчёт такта, затем бас и барабаны; гитарной партии не слышно — её играешь ты
- [ ] Сыгранная вовремя нота: плашка исчезает, кольцо струны вспыхивает, частицы, всплывает PERFECT или GOOD
- [ ] Пропущенная нота: плашка гаснет и уезжает серой, всплывает MISS, комбо сбрасывается
- [ ] Не та нота вовремя — не засчитывается (нота станет MISS), комбо не рвёт лишняя нота сама по себе
- [ ] Одна длинная нота не засчитывается несколько раз
- [ ] Быстрые повторы одной ноты (восьмые по 6-й струне) засчитываются каждая
- [ ] Хаммер-он / пулл-офф (без нового удара) — вторая нота засчитывается
- [ ] Аккорды (концовка демо, квинтаккорды) засчитываются целиком
- [ ] Звук гитары на другой октаве (детектор иногда путает) — всё равно засчитывается
- [ ] Шум, касание струн, затухающие струны не дают ложных срабатываний

## 2. HUD

- [ ] Слева: счёт растёт; кольцо множителя ×1 → ×2 → ×3 → ×4 каждые 10 нот серии; сегменты заполняются
- [ ] Справа: точность и счётчики Perfect / Good / Miss; после второй попытки — «Рекорд»
- [ ] Внизу слева: уровень входа шевелится при игре, название звуковой карты
- [ ] Внизу справа: «Задержка N мс» — правдоподобное число (у звуковой карты обычно 5–30 мс)

## 3. Тайминг

- [ ] Играя ровно по нотам, получаешь в основном Perfect, а не систематически Good
  - если почти всё Good — записать: кажется, что играешь рано или поздно? Это поправит калибровка (этап 8)
- [ ] Специально рано/поздно на ~1/16 — Good, ещё сильнее — Miss

## 4. Результаты

- [ ] После последней ноты — экран результатов, совпадает со стилем `design/04-results.png`
- [ ] Оценка (буква) и звёзды соответствуют точности; «Новый рекорд», если побил прошлый результат
- [ ] Счёт, точность, макс. комбо совпадают с тем, что было в HUD в конце
- [ ] Полоса Perfect / Good / Miss и подписи; «Лишних нот» — если были
- [ ] «Точность по ходу трека»: красные столбики там, где ошибался; «Сложный участок» указывает на них; наведение на столбик — подсказка
- [ ] «Точность по струнам»: худшая струна подписана
- [ ] «Ещё раз» — новая попытка того же трека

## 5. Свой трек

- [ ] Трек из библиотеки (`/library` → «Играть») — проходится от начала до конца, результат открывается

## 6. Прочее

- [ ] Пауза (Esc) во время игры — ноты не засчитываются и не пропускаются; «Продолжить» — честно продолжает
- [ ] «Сначала» в паузе — счёт обнуляется
- [ ] `prefers-reduced-motion`: без частиц и вспышек, оценки просто появляются и гаснут
- [ ] `?fps` — 60 fps во время игры с эффектами

## Если что-то не так — записать

Трек, струна/лад, что сыграл и что засчитано; для тайминга — ощущение «рано/поздно» и число в «Задержка N мс».
