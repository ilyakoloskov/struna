# Этап 5 — ручная проверка дорожки

Критерий этапа: стабильные 60 fps, ноты приходят на линию удара точно в своё время.
Гитара не нужна. Проверять в обычном (не headless) Chrome/Edge, лучше на основном мониторе.

## Подготовка

- [ ] `nvm use && npm run dev`
- [ ] В настройках ОС/браузера не включено энергосбережение, ограничивающее частоту кадров

## 1. Тестовые ноты без звука — `/play/test?fps`

- [ ] Вид совпадает с `design/01-game-7-strings.png` (7 стр.) и `02-game-6-strings.png` (6 стр. — сменить строй в тюнере или настройках)
- [ ] Дорожка в перспективе, уходит вдаль и растворяется; у каждой струны свой цвет; подписи струн внизу под своими линиями
- [ ] Ноты — светящиеся плашки с номером лада; длинные ноты — с хвостом
- [ ] Нота касается линии удара → кольцо её струны вспыхивает; пока звучит длинная нота — кольцо подсвечено
- [ ] Счётчик внизу слева: **60 fps**, худший кадр ≤ 20 мс (первые 1–2 секунды после старта не считаются)
- [ ] Окно на весь экран и на 4K/Retina — по-прежнему 60 fps
- [ ] Сузить окно — дорожка помещается по ширине, подписи струн остаются под своими линиями
- [ ] Esc — пауза, пробел — продолжить; «Сначала» начинает заново
- [ ] Свернуть вкладку и вернуться — стоит на паузе

## 2. Синхронизация со звуком — `/play/demo?fps`

- [ ] «Загружаю инструменты» → «Начать»; после отсчёта такта ноты приходят ровно с отсчётом
- [ ] Гитарная партия слышна (на этапе 6 её выключим — играешь ты); каждая вспышка кольца совпадает со звуком ноты
  - лучше всего слышно на открытой 6-й струне в начале риффа
  - если вспышка заметно раньше/позже звука — записать, на сколько примерно и какие наушники/колонки
- [ ] С Bluetooth-наушниками (у них большая задержка) вспышки по-прежнему совпадают со звуком — задержка вывода учитывается
- [ ] Пауза (Esc) — звук и ноты останавливаются вместе; «Продолжить» — снова синхронно
- [ ] В паузе: «Гитарная партия», «Метроном», «Отсчёт» переключаются
- [ ] Метроном включён — щелчки совпадают с поперечными линиями долей (жирные — начало такта)
- [ ] Конец трека → «Трек закончился», «Ещё раз» работает

## 3. Свой трек — из библиотеки

- [ ] Загрузить MIDI в `/library` → «Играть» → те же проверки синхронизации
- [ ] Трек со сменой темпа — линии долей и ноты не расходятся
- [ ] Ноты, которые нельзя сыграть в строе, на дорожке не появляются
- [ ] Перезагрузка страницы на `/play/<id>` → «Трек не найден» с кнопками (библиотека пока в памяти)

## 4. Доступность

- [ ] Включить «Уменьшение движения» в ОС → кольца не пульсируют, свечение мягче

## Если что-то не так — записать

Адрес, строй, разрешение экрана, fps со счётчика; для рассинхрона — на сколько и в какую сторону, устройство вывода звука.
