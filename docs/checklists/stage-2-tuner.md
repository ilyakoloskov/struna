# Этап 2 — ручная проверка тюнера с гитарой

Критерий этапа: гитара через звуковую карту стабильно определяется на всех струнах,
включая низкую B (и A в Drop A), стрелка не дёргается.

## Подготовка

- [ ] `nvm use && npm run dev`, открыть http://localhost:5173/tuner в Chrome или Edge
- [ ] Гитара подключена в инструментальный (Hi-Z) вход звуковой карты, эффекты и усилитель в цепочке выключены
- [ ] Нажать «Подключить вход» и разрешить доступ к микрофону

## Вход и уровень

- [ ] В «Устройство ввода» видна звуковая карта по названию (не только «Вход по умолчанию»)
- [ ] После выбора звуковой карты показания продолжают идти без перезагрузки страницы
- [ ] Сильный удар по струнам: индикатор зелёный, текст «Хороший уровень, без перегруза»
- [ ] Если пишет «Перегруз» — убавить гейн, пока не станет зелёным; если «Тихо» — прибавить
- [ ] Гитара в **2-м** входе карты тоже определяется: берётся самый громкий канал
- [ ] Отключить и снова подключить карту — список устройств обновляется сам

## 7 стр. · Drop A

- [ ] Переключить строй — кнопки струн меняются на A1 E2 A2 D3 G3 B3 E4
- [ ] Опустить 7-ю струну до A1 (~55 Гц): определяется, подсвечена 7-я кнопка
- [ ] На A1 стрелка спокойная, нет октавных скачков (A2 / A0)

## 6-струнные строи (если есть 6-струнная гитара)

- [ ] 6 стр. · Standard E — все струны
- [ ] 6 стр. · Drop D — D2 определяется
- [ ] 6 стр. · E♭ Standard — ноты пишутся бемолями (E♭, A♭, D♭…)

## Режимы и настройки

- [ ] Клик по кнопке струны: появился замок, отклонение считается от этой струны (если играть другую — большие центы, стрелка у края, красное свечение)
- [ ] Повторный клик по закреплённой струне — снова автоопределение
- [ ] Смена строя сбрасывает закреплённую струну
- [ ] «Свой строй…»: переключить 6/7 струн, поменять ноты — кнопки струн обновляются
- [ ] Перезагрузить страницу — выбранный строй, свой строй и устройство ввода сохранились
- [ ] При повторном открытии страницы (доступ уже выдан) тюнер включается сам, без кнопки
  - если вместо этого висит «Подключаю…» дольше секунды — **записать**: это баг
  - если появилась кнопка «Продолжить» — нажать, должно заработать

## Ресурсы и прочее

- [ ] Уйти со страницы тюнера на «Теорию» — индикатор микрофона в браузере гаснет (вход освобождён)
- [ ] Вернуться на тюнер — снова работает
- [ ] DevTools → Performance → запись 10 с во время игры: нет длинных задач в основном потоке, анимация плавная
- [ ] В консоли нет ошибок

## Если что-то не так — записать

Для каждой проблемы:

- строй и струна (например, «Drop A, 7-я, A1»);
- что видно: стрелка дрожит (на сколько центов), скачет нота (на какую), не определяется вовсе;
- когда: на атаке, в середине, на затухании;
- уровень сигнала на индикаторе;
- звуковая карта и гитара (звукосниматели: хамбакер / сингл / активные).

Что можно подкрутить по этим данным:

| Симптом | Параметр | Где |
|---|---|---|
| Стрелка дрожит | сглаживание `smoothing`, размер медианы `medianSize` | `src/audio/dsp/stabilizer.ts` |
| Нота «залипает» при смене струны | `switchFrames` | `src/audio/dsp/stabilizer.ts` |
| Не ловит тихую игру / ловит шум | `minRms`, `minClarity` | `src/audio/dsp/stabilizer.ts` |
| Октавные ошибки на низах | порог YIN `DEFAULT_YIN_THRESHOLD` | `src/audio/dsp/yin.ts` |
| Не ловит самую низкую ноту | запас `LOW_MARGIN` | `src/audio/dsp/analysisConfig.ts` |
