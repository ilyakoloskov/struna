# Этап 3 — ручная проверка теории

Критерий этапа: тесты теории зелёные, выбор тональности/лада сохраняется в URL, живой гриф работает с гитарой.
Тесты и URL проверены автоматически; с гитарой — только живой гриф (раздел 4), остальное можно без неё.

## Подготовка

- [ ] `nvm use && npm run dev`, Chrome или Edge
- [ ] `npm test` — всё зелёное

## 1. Квинтовый круг — `/theory/circle`

- [ ] Вид совпадает с `design/05-circle-of-fifths.png`: выбранная пара (мажор + параллельный минор) яркая, соседи приглушены
- [ ] Клик по внешнему сектору выбирает мажор, по внутреннему — минор; центр и заголовок обновляются
- [ ] «Знаки» верные: E мажор — F♯ C♯ G♯ D♯; F мажор — B♭; C мажор — «без знаков»
- [ ] Карточка «Параллельный минор/мажор» кликабельна и переключает тональность
- [ ] Переключатель «Мажор / Минор» даёт одноимённую тональность (E мажор ↔ E минор)
- [ ] Аккорды I ii iii IV V vi vii° с функциями T / S / D; клик по аккорду — он звучит
- [ ] Сектор F♯/G♭: выбор сохраняет текущее написание (если был G♭ — остаётся G♭)
- [ ] Tab по секторам и Enter/пробел выбирают тональность
- [ ] «Показать на грифе» → гриф с той же тональностью

## 2. Гриф — `/theory/fretboard`

- [ ] Вид совпадает с `design/06-fretboard.png` (E натуральный минор, 7 стр. Standard B)
- [ ] Сверху 1-я струна, слева подписи струн цветами струн
- [ ] Цвета ролей: тоника розовая, терция жёлтая, квинта синяя, остальные ступени тёмные
- [ ] Подписи: «Ноты» / «Ступени» (1, 2, ♭3…) / «Интервалы» (Ч1, Б2, М3…)
- [ ] Лады: «с … по …» меняет диапазон; с 0 — есть порожек, с 3 — нет
- [ ] Строй 6 ↔ 7 струн: число линий меняется, ноты пересчитываются; строй меняется и в тюнере
- [ ] Клик по любой клетке — звучит нота нужной высоты (сверить с гитарой или тюнером)
- [ ] Клик по ступени и по аккорду под грифом — звучат
- [ ] Проверить написание:
  - [ ] F мажор: B♭, не A♯
  - [ ] F♯ мажор: E♯, не F
  - [ ] G♯ гармонический минор: F𝄪 (дубль-диез)
  - [ ] A блюзовая: E♭ как ♭5
- [ ] Пентатоники и блюзовая — без строки аккордов

## 3. Ссылки (URL)

- [ ] Открыть `/theory/fretboard?key=E&mode=phrygian&tuning=7-standard-b` — E фригийский на 7 струнах
- [ ] Поменять тонику/лад/подписи/лады — URL обновляется, кнопка «Назад» не засоряется промежуточными шагами
- [ ] Скопировать URL, открыть в новой вкладке — тот же вид
- [ ] Ссылка с `tuning=7-drop-a` меняет общий строй (видно в тюнере)
- [ ] Свой строй в URL: `tuning=custom-C2-G2-C3-F3-A3-D4` — гриф в этом строе
- [ ] Мусор в URL (`key=H&mode=jazz`) — страница открывается с текущим выбором, без ошибок

## 4. Живой гриф (с гитарой)

- [ ] «Живой гриф: выключен» → клик → «слушаю вход» (зелёная), запрос доступа при первом разе
- [ ] Сыграть G3 (3-я струна открытая) в E миноре: G подсвечена белым кольцом во всех позициях, карточка «G3 · ♭3 · Входит в гамму · N позиций»
- [ ] Сыграть ноту вне гаммы (G♯ в E миноре): пунктирный кружок на всех позициях, «Не входит в гамму», написание G♯ (не A♭)
- [ ] Число позиций в карточке совпадает с числом подсвеченных кружков и зависит от диапазона ладов
- [ ] Низкие ноты (B1 / A1 на 7-струнке) подсвечиваются стабильно, без октавных скачков
- [ ] После затухания подсветка ~1 с полупрозрачная, затем исчезает
- [ ] Повторный клик выключает вход; уход со страницы гасит индикатор микрофона в браузере
- [ ] Переход тюнер → гриф → тюнер: вход каждый раз работает

## Если что-то не так — записать

Страница, URL, что ожидалось и что видно; для живого грифа — строй, струна, лад, уровень сигнала.
