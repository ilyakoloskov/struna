# Дизайн-токены STRUNA (из концепта)

## Фон и текст
| Токен | Значение | Где |
|---|---|---|
| bg | `#07070B` | фон приложения |
| surface | `#0C0C14` | дорожка, карточки |
| surface-2 | `#0F0F17` / `#11111A` | плитки, поля ввода |
| border | `rgba(255,255,255,0.08–0.18)` | рамки |
| text | `#EDEBF5` | основной текст |
| text-strong | `#F4F2FF` | цифры, заголовки |
| text-muted | `#9C98B3` | подписи, капс-лейблы |
| text-dim | `#8E8AA6` | второстепенное |

| | Цвет |
|---|---|
| Perfect | `#34E39A` (текст `#7CF5C0`) |
| Good | `#FFB020` (текст `#FFD27A`) |
| Miss | `#FF5C7A` |

## Шрифты (Google Fonts, лицензия OFL, файлы в `html/`)
- Заголовки, цифры, ноты: **Unbounded** 700–800
- Интерфейс и текст: **Manrope** 400–700
- Капс-лейблы: Manrope 700, 11–12 px, letter-spacing 0.16–0.18em

## Эффекты
- Свечение: `box-shadow: 0 0 22px <цвет 85%>, 0 0 60px <цвет 35%>`
- Радиусы: ноты 12 px, карточки 14–20 px, кнопки 12–14 px, чипы 999 px
- Дорожка: перспектива ~1100 px, наклон ~60°, линия удара с белым свечением
